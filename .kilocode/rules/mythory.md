# Mythory Kilo instructions

Follow the repository-wide contract in `AGENTS.md`.

Additional Kilo behavior:

- Use focused implementation or review modes for task-scoped work.
- Inspect relevant source and styles before editing.
- Do not introduce TypeScript or new dependencies without an explicit requirement.
- Run `npm run format` after editing and `npm run check` before finishing.
- Report lint or build failures exactly, including file and line references.
