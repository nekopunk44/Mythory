## Превью

Mythory — это концепт визуальной платформы для чтения историй и веб-новелл, оформленный как аккуратный лендинг с акцентом на контент и навигацию.

- Источник дизайна: [Figma](https://www.figma.com/design/WPZ1G2Kgkg0DT5PM3JR19V/Mythory?node-id=0-1&t=Bs7okdbhqQiqEcKM-1)
- Основной фокус: hero-блок, подбор жанров, тематические карточки и блоки обновлений
- Цель: переиспользуемая фронтенд-основа для контентного продукта

## Описание

Mythory — это витринный веб-проект для каталога историй и веб-новелл. Он оформлен как современный лендинг с акцентным hero-блоком, подборками историй, навигацией по жанрам, блоками новостей и обновлений, а также шапкой с поиском и состояниями авторизации.

## Дизайн

Визуальная часть проекта опирается на макет Figma, ссылка на который указана выше.

## Что внутри

Проект уже собран как цельная главная страница с такими блоками:

- `Header` — логотип, навигация, поиск, вход, регистрация, мобильное меню.
- `HeroSection` — главный экран с призывом начать читать или писать истории.
- `Trending` — блок популярных историй недели.
- `News` — блок свежих новостей и новых историй.
- `Top Five` — подборка лучших историй месяца.
- `GenresSection` — каталог жанров с раскрытием полного списка.
- `Latest Updates` — свежие добавления и обновления.
- `Footer` — нижняя часть страницы.

## Как использовать у себя

Чтобы забрать проект себе, выполните следующие шаги:

1. Склонируйте репозиторий:

```bash
git clone https://github.com/nekopunk44/Mythory.git
```

2. Перейдите в папку проекта:

```bash
cd Mythory
```

3. Установите зависимости:

```bash
npm install
```

4. Запустите проект в режиме разработки:

```bash
npm run dev
```

Если вы хотите использовать проект как основу для своего репозитория, достаточно сделать fork, заменить контент и при необходимости обновить ссылки на Figma, бренд и лицензирование.

## Скрипты проекта

## Мультиагентская разработка

Проект подготовлен к параллельной работе нескольких бесплатных ИИ-агентов. Общий контракт для всех инструментов — [AGENTS.md](AGENTS.md), роли — в `.github/agents`:

- `orchestrator` — декомпозирует задачу и раздаёт её остальным ролям.
- `frontend` — реализует React-компоненты, интерактивность и Sass-стили.
- `ux-reviewer` — только читает код: адаптивность, доступность, визуальная согласованность.
- `qa` — проверяет diff, формат, линтер и production-сборку.

Инструменты:

| Инструмент                      | Где работает | Настройки в репозитории                                                            |
| ------------------------------- | ------------ | ---------------------------------------------------------------------------------- |
| [OpenCode](https://opencode.ai) | терминал     | `opencode.json` — те же четыре роли, оркестратор вызывает остальных как субагентов |
| [Kilo Code](https://kilo.ai)    | VS Code      | `.kilocode/rules/`                                                                 |
| [Cline](https://cline.bot)      | VS Code      | `.clinerules`                                                                      |
| GitHub Copilot Free             | VS Code      | `.github/copilot-instructions.md`, `.github/agents`                                |

Каждый агент работает в отдельной копии репозитория (git worktree) и в своей ветке, поэтому агенты не мешают друг другу:

```bash
npm run agent:new -- genre-card-hover   # ../Mythory-agents/genre-card-hover, ветка agent/genre-card-hover
cd ../Mythory-agents/genre-card-hover && opencode
npm run agent:remove -- genre-card-hover  # после слияния PR
```

Агентов можно запускать в фоне, без ручных шагов — по номеру задачи из GitHub Issues:

```bash
npm run agent:ready        # какие задачи можно взять прямо сейчас
npm run agent:run -- 8     # создать рабочую папку и запустить агента на задаче #8
```

Скрипт сначала берёт модели [Coarena](https://coarena.ai) ($5 в день, не больше двух агентов одновременно), затем бесплатные модели OpenCode Zen и Kilo. Если у модели кончился лимит или она перестала отвечать, он переключается на следующую. Ключ Coarena кладётся в `.env.local` как `COARENA_API_KEY=...`; без ключа используются только бесплатные модели. Журнал каждого агента — в `../Mythory-agents/logs/`.

Перед отправкой агент запускает `npm run check` — ровно то, что гоняет CI (`.github/workflows/ci.yml`): проверку формата Prettier, ESLint и сборку.
