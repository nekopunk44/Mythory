## Превью

Mythory — это концепт визуальной платформы для чтения историй и веб-новелл, оформленный как аккуратный лендинг с акцентом на контент и навигацию.

- Источник дизайна: [Figma](https://www.figma.com/design/WPZ1G2Kgkg0DT5PM3JR19V/Mythory?node-id=0-1&t=Bs7okdbhqQiqEcKM-1)
- Основной фокус: hero-блок, подбор жанров, тематические карточки и блоки обновлений
- Цель: переиспользуемая фронтенд-основа для контентного продукта

## Описание

Mythory — это витринный веб-проект для каталога историй и веб-новелл. Он оформлен как современный лендинг с акцентным hero-блоком, подборками историй, навигацией по жанрам, блоками новостей и обновлений, а также шапкой с поиском и состояниями авторизации.

## Дизайн

Визуальная часть проекта опирается на макет Figma, ссылка на который указана выше.

## Что внутри

Проект уже собран как цельная главная страница с такими блоками:

- `Header` — логотип, навигация, поиск, вход, регистрация, мобильное меню.
- `HeroSection` — главный экран с призывом начать читать или писать истории.
- `Trending` — блок популярных историй недели.
- `News` — блок свежих новостей и новых историй.
- `Top Five` — подборка лучших историй месяца.
- `GenresSection` — каталог жанров с раскрытием полного списка.
- `Latest Updates` — свежие добавления и обновления.
- `Footer` — нижняя часть страницы.

## Как использовать у себя

Чтобы забрать проект себе, выполните следующие шаги:

1. Склонируйте репозиторий:

```bash
git clone https://github.com/nekopunk44/Mythory.git
```

2. Перейдите в папку проекта:

```bash
cd Mythory
```

3. Установите зависимости:

```bash
npm install
```

4. Запустите проект в режиме разработки:

```bash
npm run dev
```

Если вы хотите использовать проект как основу для своего репозитория, достаточно сделать fork, заменить контент и при необходимости обновить ссылки на Figma, бренд и лицензирование.

## Скрипты проекта

Соберите production-версию:

```bash
npm run build
```

Проверьте код линтером:

```bash
npm run lint
```

Предпросмотр production-сборки:

```bash
npm run preview
```

## Структура проекта

- `src/components` — базовые UI-компоненты.
- `src/layouts` — шапка, подвал и общие layout-блоки.
- `src/sections` — секции главной страницы.
- `src/styles` — глобальные стили, переменные, миксины и утилиты.
